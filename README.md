# 图片晾衣绳 · Windows 本地试用版

将复制的图片、截图和电脑里的图片文件挂在屏幕顶部。中文界面，只在主屏幕显示；没有账号、上传、云同步或自动更新。

## 运行

双击 `src\bin\ImageClothesline.exe`，保留同目录下的 `ImageClothesline.exe.config`。

这是本地编译的 64 位试用程序，尚未签名或公开发布。需要 .NET Framework 4.8 或兼容的更高 4.x 环境；当前开发电脑已具备 4.8，没有安装新软件。Windows 11 及其他电脑的兼容性仍须实测。

首次启动选择“开启自动收纳”或“暂不开启”。右下角托盘出现黑绳、照片和星星图标；如果图标被收起，请点击托盘展开箭头。

## 使用

1. 开启收纳后，使用现有截图工具截图、复制网页里的图片，或在文件夹中选中一张或多张照片按 Ctrl+C。截图工具需要将图片复制到剪贴板（截图后能直接 Ctrl+V 粘贴）；仅保存到文件夹、没有执行复制的截图不会自动收纳。图片保存成功后，晾衣绳会自动展开约 2 秒；鼠标移到照片上可继续操作，前台全屏时不弹出。
2. 鼠标在主屏幕顶部任意位置停留 250 毫秒，绳子横跨屏幕全宽展开。也可双击托盘图标，或通过托盘菜单显示。
3. 将电脑里的图片文件拖到展开的照片或空状态提示上，可以一次拖入多张。图片超过一屏时，照片下方显示“↔ 滚动鼠标滚轮，左右查看更多图片”，在照片上滚动滚轮横向浏览；能全部放下时提示自动隐藏。有操作提示时优先显示操作提示。
4. 单击松开立即开始复制，成功后显示“已复制”与动效；双击的第二下打开预览，不重复复制（第一下已经可能复制）；右键提供复制、预览和移除。鼠标停在照片上直接按 Del 或退格键（Backspace），会将这张工具副本送入回收站，不弹确认或成功提示；长按只处理一张，松开再按才处理下一张。鼠标离开照片后，两种键均交回前台软件。设置窗口打开时也可悬停删除；预览、拖动、菜单和正在执行操作期间继续暂停快捷删除。
5. 拖到文件夹或接受文件拖放的软件后，卡片自动取下。按 Esc 取消或目标拒绝时保留。
6. 离开后约 500 毫秒向上收起；全屏应用前台运行时不自动展开，托盘仍提供手动显示。

展开时显示黑色绳子、银色夹子和照片，背景透明；绳子左右各有 6 颗浅黄、浅粉、浅蓝星星，大小约 18～26 像素，像贴纸一样直接贴在线上，没有吊线、不闪烁；两侧保留星星区域，照片在中间横向滚动，不与星星重叠；绳子两端略高、中间浅浅下垂，展开时中间轻轻下沉再回稳；照片落下后短暂摆动并停稳；鼠标移入时照片轻微放大约 4%，移开后在约 180 毫秒内恢复，不挤动相邻图片。已移除照片右上角的小方框和悬停文字提示。点击时照片立即轻动；复制成功后在照片下方留出空隙显示“已复制”，照片与提示一起轻动，提示约 1.2 秒后消失。设置、暂停和退出在托盘菜单中。

单击不再等待系统双击判断时间；只有复制成功后才显示“已复制”。因此双击包含的第一下点击也会开始复制，不能同时保证双击完全不改变剪贴板。点击复制时，后台读取已有 PNG 和图片像素，直接复用 PNG 数据，不再在界面线程重新压缩；图片尺寸、颜色和透明度保持不变。大图读取或剪贴板忙碌时，成功提示仍可能稍有延迟。托盘手动显示后留出约 3 秒移动鼠标的时间。

支持 PNG、JPG/JPEG、BMP、GIF、TIF/TIFF。GIF 和 TIFF 仅收纳第一帧或第一页；工具副本统一转为静态 PNG，导入原件保持不变。WebP、SVG、HEIC 等暂不支持。超过 6400 万像素的图片会明确拒绝，避免过大的内存占用。

## 收纳开关

托盘 → 设置中，“自动收纳复制的图片”是总开关；关闭后所有自动收纳暂停，仍可手动拖入文件。

“收纳复制的图片文件”默认开启，包括从旧版升级；你关闭后会保存选择，重启不会自动改回开启。关闭这个子开关只停止文件夹中的照片复制收纳，不影响截图和网页图片。重新开启只处理之后的新复制，不补收当前旧剪贴板。

支持一次复制多张已有支持格式的照片；文件夹、普通文档和带剪切标记的文件不会加入。不扫描文件夹，也不移动或修改原文件；支持格式中有损坏或不可读图片时显示失败提示，其他有效图片继续收纳。文件复制与剪切标记的实现依据：[微软 Shell 剪贴板格式说明](https://learn.microsoft.com/en-us/windows/win32/shell/clipboard)。

## 保存与清理

保存在当前用户的 `%LOCALAPPDATA%\ImageClothesline` 下：

- `images`：工具保存的静态图片副本。
- `thumbnails`：显示缩略图。
- `state.json`：卡片状态、加入时间和收纳设置。
- `state.backup.json`：上一份完整记录。

设置中的“打开保存目录”可以直接找到这些文件。

成功拖出仅表示目标接受了复制拖放，不代表消息已经发送。取下后继续保留副本，供目标稍后读取。发送完成后进入“设置 → 清理已取下图片”，确认后送入回收站；没有定时清理。

手动移除也会将工具副本及其缩略图送入回收站。Del 和退格键均不弹确认或成功提示；右键移除仍保留确认。操作失败仍会说明原因。如果副本已回收、但记录保存失败，卡片仍会取下，并明确说明可以从回收站找回。系统未确认回收成功时保留记录，绝不改用永久删除。回收站找回的图片可以重新拖入。

仍挂着的图片不会被“清理已取下图片”清理。桌面、下载文件夹等位置的导入原件不移动、不删除。退出会等待正在进行的保存任务。

## 构建与测试

当前可用系统自带 C# 编译器，无第三方包、安装或联网步骤。打开项目目录下的终端运行：

    .\src\build.cmd
    .\tests\run-tests.cmd --ui --native-recycle --startup

系统目前限制 PowerShell 脚本执行，因此默认使用上述 CMD 入口，没有修改执行策略。也保留 PowerShell 入口，供已有允许策略的开发环境使用。

构建结果位于 `src\bin`。测试使用独立生成的样例文件；`--native-recycle` 会把测试生成的副本送入系统回收站，不处理用户图片。UI 测试会短暂打开测试窗口，并在 `tests\artifacts` 导出界面示例。

另提供 `src\ImageClothesline.csproj`，供配备 Framework 4.8 开发引用包的 Visual Studio/MSBuild 使用。如果这条方式缺少组件，需要先确认安装方案；运行已生成的程序不需要开发工具。

## 验收边界

- 本地存储、恢复、去重、剪贴板收纳规则、拖出状态规则、真实 WPF 图片显示、虚拟化和系统回收站和托盘启动关闭已有自动测试。
- Del 和退格键采用 Windows 按键钩子，仅在工具可见、指针停在照片上且没有拖动/菜单/预览等操作时处理普通 Del 或退格；不记录按键，Ctrl/Shift/Alt/Win 组合键交还其他软件。隐藏后和退出后不处理删除。实现依据：[微软按键钩子说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc)。
- 自动测试不能替代微信/QQ 实际操作。版本、文件拖放接受方式和程序权限可能影响结果；不接受拖放的应用可用“点击复制 → 粘贴”。
- 多倍率渲染图仅验证渲染，不代表对应系统缩放比例和 Windows 11 已实测。
- 现有截图工具的通知、快捷键和保存方式不变。
- 开启收纳会将随后复制的图片保存到本机，含敏感内容时可以通过托盘暂停。
- 没有自动容量清理，图片较多时请查看已取下占用并手动处理。
