# 图片晾衣绳

把截图和复制的图片挂在屏幕顶部，随时复制、预览、拖出去用。

Windows 图片收纳小工具。图片只保存在本机，不上传、不需要账号。配合现有截图软件使用，本身不负责截图。

## 下载和打开

**[下载 v0.1.0 Windows 免安装版（ZIP）](https://github.com/LY134774/ImageClothesline/releases/download/v0.1.0/ImageClothesline-v0.1.0-win-x64.zip)** · [版本说明](https://github.com/LY134774/ImageClothesline/releases/tag/v0.1.0)

1. 下载 ZIP，完整解压到一个固定文件夹。
2. 双击 **ImageClothesline.exe**，保留旁边的 **ImageClothesline.exe.config**。
3. 首次打开，选择 **开启自动收纳**。

不要直接在压缩包里运行。GitHub 的 **Source code** 是源码包，普通用户请选择上面的 Windows 免安装版。

- 面向 Windows 10 / Windows 11 **64 位电脑**，需要 **.NET Framework 4.8**。
- 当前已在 Windows 10 验证；Windows 11 和其他屏幕缩放仍待实测。
- 首个公开试用版，尚未做软件数字签名，Windows 可能显示安全提示。请核对下载来源，不要关闭系统安全防护。

## 怎么使用

| 想做什么 | 怎么操作 |
| --- | --- |
| 收纳截图 | 用原来的截图工具截图，并复制到剪贴板 |
| 收纳电脑里的照片 | 在文件夹选中照片，按 **Ctrl+C**，或把图片文件拖上绳子 |
| 展开晾衣绳 | 鼠标移到主屏幕顶部，稍作停留 |
| 复制图片 | **单击**照片，看到“已复制”后，到目标软件按 **Ctrl+V** |
| 查看大图 | **双击**照片，按 **Esc** 或关闭窗口退出预览 |
| 拖出使用 | 拖到文件夹或接受图片拖放的软件 |
| 删除卡片 | 鼠标停在照片上按 **Del** 或 **Backspace**，副本送入回收站 |
| 查看更多图片 | 照片放满后，在照片上滚动鼠标滚轮，左右浏览 |
| 暂停、设置、退出 | 右键电脑右下角托盘中的图片晾衣绳图标 |

新图片收纳成功后，绳子会短暂展开提醒。鼠标移开后自动收起；全屏应用运行时不自动弹出，可以从托盘手动显示。

**双击的第一下也会开始复制，第二下打开预览。** 这样单击不必等待双击判定。

## 收纳开关

打开 **托盘 → 设置**：

- **自动收纳复制的图片**：总开关，关闭后暂停自动收纳，仍可手动拖入。
- **收纳复制的图片文件**：默认开启。关闭后不收纳文件夹里 Ctrl+C 复制的照片，截图和网页图片仍可收纳。

只保存到文件夹、没有复制到剪贴板的截图，不会自动加入。文字、文件夹和剪切的文件不会收纳。

## 保存与清理

打开 **托盘 → 设置 → 打开保存目录** 查看图片。数据保存在 `%LOCALAPPDATA%\ImageClothesline`，退出和重启后会恢复。

- 导入时保存工具自己的副本，不改动原始照片。
- 成功拖出后，卡片取下，副本仍保留。确认目标软件读取完成后，可在设置里 **清理已取下图片**。
- Del / Backspace 删除不再弹确认。删除和清理的副本进入系统回收站，需要时可以找回。
- 没有定时自动清理；删除程序文件夹不会同时清除已收纳的数据。

## 支持范围与常见问题

- 支持 PNG、JPG/JPEG、BMP、GIF、TIF/TIFF；动图和多页图片只保存第一帧或第一页。
- 目前只显示在主屏幕，不支持 WebP、OCR、标注和多屏。
- **找不到窗口？** 看右下角托盘，图标可能藏在展开箭头里，右键选择“显示晾衣绳”。
- **图片没有加入？** 检查自动收纳是否开启，以及截图工具是否把图片复制到了剪贴板。
- **拖到某个软件没反应？** 对方可能不接受拖放，可改用单击复制再粘贴。拖放被接受不代表聊天消息已发送。
- **出现异常？** 到 [Issues](https://github.com/LY134774/ImageClothesline/issues) 描述操作步骤、Windows 版本和提示内容；截图前注意遮住私人信息。

已知待观察项：预览曾在自动检查中偶发未打开，后续检查正常，原因尚未确定。各聊天软件的完整粘贴、拖放体验仍欢迎反馈。
